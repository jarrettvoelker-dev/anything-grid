# Anything Grid

行列交叉填词。每格填一个**同时满足它所在行条件与列条件**的事物。
支持 2×2 / 3×3 / 4×4 / 5×5，可创建自己的题、发布、分享。

## 现在能玩什么

- **2D 空间画布**：无限平面，滚轮/捏合缩放，空格+拖拽平移，Shift 拖拽框选，Delete 清空，Ctrl/Cmd+Z 撤销
- **核心玩法**：点格子直接作答，回车判定；重复答案与错误答案即时反馈
- **相似搜索**：精确 → 别名 → 同义词 → 语义 → 类别校验 → 置信度。关闭后只认完全一致的答案
- **创建器**：自定义行列条件、每格多个正确答案（含别名、同义词、描述、配图）、实时预览、自动存草稿
- **自动填充**：已在别处答对的内容，遇到同样接受它的空格会自动补上（每次都过条件校验）

## 开发

```bash
npm install
npm run dev          # http://localhost:5173
npm test             # 单元测试：匹配引擎 + 撤销栈
bash scripts/run_e2e.sh   # 端到端：真浏览器里驱动 UI（需要 Windows 自带 Edge）
npm run build        # 构建到 dist/
```

## 架构

```
src/
├── lib/
│   ├── match.ts      相似搜索流水线（纯函数，语义档可注入 resolver）
│   ├── history.ts    快照式撤销栈（带合并，拖拽不会塞满记录）
│   ├── types.ts      数据模型
│   ├── storage.ts    本地存档（M2 换成服务端后降级为草稿箱）
│   └── samples.ts    示例题库（2×2 ～ 5×5）
├── state/store.ts    单 store：文档 + 历史 + 选择 + 视口
├── components/
│   ├── CanvasPlane.tsx  无限画布（手势矩阵、惯性、缩放锚点）
│   ├── Board.tsx        棋盘（渲染在画布的世界坐标层里）
│   └── ui.tsx           设计系统基元
└── views/               Home / Play / Creator
```

## 路线图

- [x] **M1** 前端底座 + 2D 画布 + 核心玩法 + 创建器（当前）
- [ ] **M2** 后端（Cloudflare Workers + D1）：答案移到服务端、发布状态、`/grid/:id` 稳定链接
- [ ] **M3** 服务端相似搜索 + 创建者 BYOK 语义档 + 结果分享卡片
- [ ] **M4** 3D 视图回归、限流与答案隐藏审计

## 关键设计决定

**为什么答案判定要走服务端（M2）**：现在答案存在浏览器里，打开开发者工具就能看光。
M2 会把判定挪到服务端，前端只拿得到"对/错/接近 + 置信度"。

**为什么语义档的 API Key 必须由创建者提供**：语义匹配要把答案和猜测一起喂给模型。
如果 Key 是玩家的，玩家可以把接口地址指到自己的服务器，从而读到答案。
创建者本来就知道答案，所以只有创建者提供 Key 才不产生新的泄露面。
